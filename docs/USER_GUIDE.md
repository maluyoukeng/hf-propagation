# hf-propagation · 使用说明

本文档面向普通使用者，介绍 FoloToy AI Passport 上 **hf-propagation**
短波传播预测应用的
开机、按键、预测查看、参数设置、WiFi 配网、数据更新和自动定位。

[English](USER_GUIDE.en.md) · [返回 README](../README.md)

---

## 1. 适用范围

本应用用于业余无线电短波通联规划，根据以下输入估算传播条件：

- 太阳通量指数 `SFI`
- 地磁指数 `Kp`
- 收发地点经纬度
- 当前 UTC 时间与日期
- 目标区域

输出包括 `MUF`、`LUF`、路径距离、方位角、昼夜路径比例、各波段评分、
最佳波段和 24 小时最佳时段。

> 预测是简化模型的估算值，不等于实测传播，也不替代专业软件。实际通联还受
> 天线、功率、噪声、地形、电离层扰动和操作水平影响。

## 2. 设备准备

- FoloToy AI Passport 设备
- 支持数据传输的 USB-C 线（刷机或查看串口日志时使用）
- 一个可用的 2.4 GHz WiFi 网络（数据更新和自动定位时使用）
- 手机或电脑（用于打开设备的 WiFi 配置网页）

设备只支持 2.4 GHz WiFi；5 GHz 网络无法连接。

## 3. 按键

设备有三个实体按键：

| 按键 | 短按 | 长按 |
| --- | --- | --- |
| `UP` | 向上移动；切换波段；增加数值 | 无 |
| `DOWN` | 向下移动；切换波段；减少数值 | 无 |
| `OK` | 进入、确认、开始更新 | 返回上级；参数设置中保存并返回 |

在参数编辑状态，长按 `OK` 会取消本次编辑并恢复编辑前的值。

## 4. 开机与主界面

开机后显示“传播预测”总览页：

- 当前选中的波段
- `MUF` 与 `LUF`
- 当前波段的评分和可用性评级
- 最佳波段提示
- 站点、目标区域、SFI、Kp 和本地时间摘要

短按 `UP` / `DOWN` 切换波段，短按 `OK` 进入该波段的详情页。
长按 `OK` 进入主菜单。

## 5. 查看预测

### 5.1 总览页

总览页用于快速判断“现在哪个波段最值得尝试”。评分越高、评级越好，
表示在当前模型下该波段越可用。

评级含义：

| 评级 | 含义 |
| --- | --- |
| 差 | 当前条件下不建议优先尝试 |
| 一般 | 可以尝试，但成功率有限 |
| 好 | 较有利的通联条件 |
| 优秀 | 模型判断的最佳条件 |

### 5.2 波段详情

在总览页短按 `OK` 进入详情页，显示：

- 波段名称与频率
- 评分与评级
- 最佳时段（UTC 或本地时间，取决于当前时区设置）
- 昼间路径比例
- 收发地点距离
- 方位角

短按 `UP` / `DOWN` 可在波段之间切换；长按 `OK` 返回总览。

### 5.3 最佳时段

“最佳时段”是模型在 24 小时内按 30 分钟步长扫描得到的最高评分区间。
它用于规划通联时间，不代表该时段一定能够通联。

## 6. 参数设置

从主菜单进入 `参数设置`。可用字段：

| 字段 | 说明 |
| --- | --- |
| 站点 | 发射地点：北京、上海、广州、成都、乌鲁木齐、哈尔滨、拉萨、海口，或“自动定位” |
| 目标 | 目标区域 |
| 时区 | 本地时间相对 UTC 的偏移，步长 30 分钟 |
| SFI | 太阳通量指数，范围 70–250 |
| Kp | 地磁指数，范围 0–9 |
| UTC 时间 | 手动设置设备时间 |
| 日期 | 手动设置日期 |
| 定位 | 只读显示：未定位或当前经纬度 |

操作方式：

1. 短按 `UP` / `DOWN` 在字段间移动。
2. 短按 `OK` 进入编辑。
3. 短按 `UP` / `DOWN` 调整值。
4. 短按 `OK` 确认当前值。
5. 长按 `OK` 保存并返回；编辑中长按 `OK` 取消。

## 7. 自动定位

### 7.1 选择自动定位

1. 进入 `参数设置`。
2. 选中“站点”行，短按 `OK` 进入编辑。
3. 按 `UP` 或 `DOWN` 切到 **自动定位**。
4. 短按 `OK` 确认，长按 `OK` 保存。

此时“定位”行可能显示“未定位”，底部提示“自动定位：联网更新时获取”。

### 7.2 获取位置

1. 先完成 WiFi 设置。
2. 进入 `数据更新`，短按 `OK`。
3. 设备状态显示“正在获取网络位置...”。
4. 成功后，“定位”行显示经纬度，例如 `36.96N 117.21E`。
5. 随后设备继续获取 NOAA 数据并重新计算预测。

位置会写入 NVS，重启后保留。以后每次数据更新都会刷新位置。

### 7.3 定位原理和限制

- 使用路由器对外的**公网 IP**，由第三方服务返回城市级经纬度。
- 不是 GPS，也不是扫描附近 WiFi AP 的三角定位。
- 通常精确到城市；VPN、代理、运营商出口、企业网络可能导致偏差。
- 定位失败时保留上次坐标；从未定位过时按北京坐标估算。
- 如果自动定位偏差较大，请在“站点”中改选离你最近的内置城市。
- 定位请求会把公网 IP 发送给 `ip-api.com` 等服务；不需要账号或 API Key。

## 8. WiFi 设置

### 8.1 开启设备热点

1. 从主菜单进入 `WiFi 设置`。
2. 短按 `OK` 开启热点。
3. 屏幕显示热点名称、密码和网页地址：
   - SSID：`AI-PASSPORT-XXXXXX`
   - 密码：`aipassport`
   - 网页：`http://192.168.4.1`

再次短按 `OK` 可停止热点。

### 8.2 连接并配置路由器 WiFi

1. 手机或电脑连接设备热点 `AI-PASSPORT-XXXXXX`。
2. 浏览器打开 `http://192.168.4.1`。
3. 网页会自动扫描附近的 2.4 GHz WiFi。
4. 点击列表中的目标 WiFi，SSID 会自动填入。
5. 输入 WiFi 密码，点击“保存 WiFi”。
6. 保存后设备会断开配置热点，回到设备页面。

如果扫描时热点短暂断开，网页会自动重试；等待几秒即可。

### 8.3 重新配网

进入 `WiFi 设置`，重新开启热点，用手机/电脑连接后修改 SSID 或密码并保存。

## 9. 数据更新

1. 确认已完成 WiFi 设置。
2. 从主菜单进入 `数据更新`。
3. 短按 `OK`。
4. 设备依次显示：
   - 正在连接 WiFi...
   - 正在获取网络位置...（仅自动定位或尚未保存位置时）
   - 正在获取传播数据...
   - 数据已更新
5. 更新成功后，屏幕显示 `SFI`、`Kp`、`A` 指数和 NOAA 发布时间。
6. 设备会自动写入 SFI/Kp，重新计算各波段预测，然后断开 WiFi。

NOAA 地址：<https://services.swpc.noaa.gov/text/wwv.txt>

更新可能受以下因素影响：

- 路由器无法访问互联网
- WiFi 密码错误或信号过弱
- DNS/防火墙阻止 NOAA 或定位服务
- 首次 TLS 连接较慢

失败时短按 `OK` 重试；多次失败请检查 WiFi 和网络。

## 10. 常见问题

### 10.1 页面显示“请先设置 WiFi”

尚未保存路由器 WiFi。进入 `WiFi 设置`，用手机或电脑完成配网。

### 10.2 设备热点找不到

- 确认已进入 `WiFi 设置` 并按 `OK` 开启热点。
- 手机/电脑只支持 2.4 GHz 扫描时也能看到该热点；如果看不到，靠近设备重试。
- 热点开启后最多允许 2 个客户端连接。

### 10.3 网页扫描不到我的 WiFi

- 确认路由器使用 2.4 GHz，而不是仅 5 GHz。
- 靠近路由器后点击“重新扫描”。
- 隐藏 SSID 不会出现在列表中，可手动输入 SSID。

### 10.4 自动定位显示“未定位”

- 需要先完成 WiFi 设置并执行一次 `数据更新`。
- 定位服务可能被网络阻止；可改选固定城市。
- 定位成功后坐标会显示在“定位”行，并在重启后保留。

### 10.5 定位城市不对

IP 定位只到城市级，且受 VPN/代理/运营商出口影响。请在站点中选择最近的
内置城市，或等待网络环境变化后重新更新。

### 10.6 更新后 SFI/Kp 没有变化

NOAA 的 WWV 文本可能尚未发布新值；设备显示的是最近一次发布时间。
也可以手动在参数设置中修改。

### 10.7 时间不对

在 `参数设置` 中调整 `UTC 时间`、`日期` 和 `时区`。时区步长为 30 分钟。

## 11. 隐私与免责声明

- WiFi 密码保存在设备本地 NVS，不会上传到本项目作者的服务器。
- 执行网络定位时，公网 IP 会发送给第三方定位服务。
- NOAA 数据和定位结果仅作为传播估算输入。
- 本项目是社区衍生应用，不是 FoloToy 官方固件；使用风险由使用者自行承担。

## 12. 恢复与刷机

- 只想清除 WiFi：重新进入 `WiFi 设置` 配网。
- 想恢复默认参数：刷入完整镜像（会写入 bootloader、分区表和 OTA 数据；
  是否清除 NVS 取决于刷写范围，建议先记录重要参数）。
- 只想更新应用并保留 WiFi/参数：使用 `0x20000` 的 app-only 镜像，并确认
  分区布局一致。

详细命令见 [BUILD.md](BUILD.md)。
